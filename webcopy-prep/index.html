Stereophile Web Copy Prep

Drop in a Word, RTF, plain-text, or HTML file. The page converts it to bare HTML (paragraphs, italic, bold, superscripts, and subscripts only), applies the mechanical rules of the house style guide, and lists every change it made. The file never leaves your browser.

Spell-check and proofread the copy first, in whatever program it came from. This page applies house style only; it does not proofread.

What this page changes
  • Curly quotes and apostrophes become straight
  • Four-digit numbers lose their comma (8,000 → 8000); five digits keep it
  • Prices drop .00 ($1,299.00 → $1299)
  • Spaced dashes and double hyphens become a closed em dash
  • Units close up to numerals (20 Hz → 20Hz, 92 dB → 92dB); lb stays spaced and singular
  • Power output to Wpc (100 watts per channel → 100Wpc)
  • Ω becomes ohms (8Ω → 8 ohms); before a noun, a hyphenated singular (8-ohm speakers)
  • Bit depth and sample rate to 24/96 form
  • percent → %; i.e./e.g. → ie,/eg,; vs. → vs
  • Negative numbers take an en dash (-3dB → –3dB); unit ranges take an en dash
  • Decades: 90's → '90s, 1990's → 1990s
  • Ellipses: ... → … with a space each side
  • No hyphen after -ly adverbs (highly-regarded → highly regarded)
  • S/PDIF, TOSLINK, setup, masterclass, and the style guide's closed compounds and US spellings
  • http://, https://, and www. removed from addresses
  • Doubled words (the the), double spaces, space before punctuation
  • Stereophile set in italic
  • Subheads (Word’s 05-subhead or Heading styles, HTML headings, short all-bold lines, and in plain text short unpunctuated lines) are set as <p><strong>Subhead</strong><br> at the start of the next paragraph; a terminal period is removed, title case is flagged, and every subhead is listed for checking
  • Text that already has HTML: <b>/<i> and styled spans become <strong>/<em>; italic and bold set in a stylesheet are kept; loose lines are wrapped in <p>; links, spans, and other tags are removed, keeping their text; from a whole web page, only the article is kept (CSS, scripts, header, menus, sidebars, and footer go)
